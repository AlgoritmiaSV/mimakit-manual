# Citas

---

## Listado de citas

Para ver el listado de citas, vaya a: **Clínica > Citas**.

![Listado de citas](../img/clinica/listado-citas.png)

---

## Registrar nueva cita

Para registrar una nueva cita, vaya a: **Clínica > Citas**, y luego dar clic en el botón **+**.

![Registrar nueva cita](../img/clinica/nueva-cita.png)
