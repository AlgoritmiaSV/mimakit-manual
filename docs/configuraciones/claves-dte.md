# Claves DTE

En el Sistema de Documentos Tributarios Electrónicos (DTE) de El Salvador, las claves o credenciales hacen referencia principalmente a dos elementos indispensables para firmar y transmitir facturas ante el Ministerio de Hacienda.

---

## Modificar claves DTE

Para modificar las claves DTE, vaya a: **Configuraciones > Claves DTE**.
